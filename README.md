# Zomato-Dashboard-Power-BI
Interactive Power BI dashboard analyzing Zomato’s sales, orders, ratings, and cuisine trends across countries and cities. Features KPIs, maps, and charts to track top restaurants, veg vs non-veg demand, and year-wise growth. Designed for quick insights into performance, customer preferences, and market trends.

## 📂 Features
<ul>
<li>KPIs: Quantity (2M), Sales (987M), Orders (150K), Ratings (148K)
<li>Filters: Country, Restaurant, Cuisine
<li>Visuals: 📈 Charts, 🗺️ Maps, 📊 Cards, 📆 Trends
</ul>

## Insights:
<ul>
<li>🥗 Veg vs 🍗 Non-Veg demand
<li>Top cities by sales & orders
<li>Year-wise growth trends
</ul>

## 🛠 Tools & Data
<ul>
  <li>Tool: Power BI Desktop</li>
  <li>Data Source: Zomato dataset export</li>
  <li>Visual Types: KPIs, bar charts, line charts, cards, maps, slicers</li>
</ul>


## 🎯 Key Benefits
✔ Identify top-performing restaurants & cities <br>
✔ Understand cuisine preferences & cost trends <br>
✔ Monitor sales growth over time <br>
✔ Country-specific performance analysis <br>
